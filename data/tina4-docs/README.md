# Bundled Tina4 documentation (offline grounding)

The harness grounds its Tina4 answers on these docs **offline** — no network, no `tina4 docs`.

- `python/` — tina4-python framework docs (43 chapters)
- `js/`     — tina4-js framework docs (19 chapters)

Fetched 2026-10-10 with `tina4 docs` (client tina4 3.8.97).
Refresh: run `tina4 docs` in a tina4-python project and a tina4-js project, then copy the
resulting `.tina4-docs/*.md` into `python/` and `js/` respectively.
